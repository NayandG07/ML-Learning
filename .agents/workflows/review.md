Review the feature the developer just implemented.

Do NOT automatically modify the code.

## Review

Evaluate:

### 1. Functionality

Does the feature actually work?

### 2. Code Quality

Is the implementation readable and understandable?

### 3. Architecture

Does it fit the existing project structure?

### 4. Error Handling

What happens when something goes wrong?

### 5. Security

Are there obvious security problems?

### 6. Edge Cases

What situations might break the implementation?

### 7. Testing

What should be tested?

### 8. Understanding

Ask the developer 2-4 questions about their implementation.

The questions should test whether they understand what they built,
not whether they memorized syntax.
