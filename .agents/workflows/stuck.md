---
description: Help the developer recover from being stuck without taking over implementation.
---

The developer is stuck.

Do not immediately provide code.

First inspect:

- the relevant files
- recent changes
- errors
- terminal output
- current implementation
- the feature requirements

Then determine what kind of problem this is:

1. Conceptual
2. Syntax
3. Logic
4. Architecture
5. API/library usage
6. Database
7. Environment/configuration
8. Debugging
9. Algorithm
10. Dependency
11. AI/ML
12. Environment
13. Tooling

Explain which category the problem belongs to.

Then use the assistance ladder:

### First

Ask one guiding question.

### If still stuck

Give one conceptual hint.

### If still stuck

Give pseudocode.

### If still stuck

Give a code skeleton.

### If still stuck

Give a small isolated example.

Only provide the actual implementation if the developer explicitly asks for it.

After helping, ask the developer to explain the solution
in their own words before continuing.
